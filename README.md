# 💸 BudgetBloom – Personal Finance Tracker & Goal Visualizer

**BudgetBloom** is a full-stack web application designed to help users take control of their finances. Users can securely log expenses, set savings goals based on their income, and view insightful graphs to understand their spending patterns.

---

## 🔧 Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express.js
- **Database:** SQL (MySQL/PostgreSQL)
- **Authentication:** JWT (JSON Web Tokens)
- **Deployment:** VPS with NGINX and PM2

---

## 🚀 Features

- 🧾 **Expense Tracking**
  - Add, edit, and delete daily expenses
  - Categorize and filter by date or category

- 🎯 **Savings Goal Module**
  - Set your **monthly income** and desired **saving amount**
  - Track how much you've actually saved (`income - expenses`)
  - View progress with visual indicators

- 📊 **Spending Insights**
  - Pie chart of category-wise spending
  - Bar/line graph of spending over time

- 🔐 **User Authentication**
  - Secure login/signup with email and password
  - JWT-based token authentication for all protected routes
